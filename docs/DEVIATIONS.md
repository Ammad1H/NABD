| D3 | 2026-11-08 | Pre-test (added after freeze, before any test-season forecast was produced) | **Alert layer pre-specified for BUILD-SPEC G10 (US-A).** Surge onset for a location-season = the first week whose truth weekly rate is ≥ T per 100k for two consecutive weeks; T ∈ {2, 3, 5}, primary T = 3. The first alert per location-season counts. **Lead** = (onset week end − R)/7 weeks. **Sensitivity** = share of eligible onsets whose first alert has lead 0–4 weeks. **Premature** = first alert > 4 weeks before onset. **False alarm** = alert in a location-season with no onset. **PPV** = first alerts followed by onset within 4 weeks / all first alerts. Location-seasons already at or above T at the first reference date are ineligible and are counted. **Data latency:** report the input-to-issue lag and stale rounds. **Feed-dropout robustness:** re-run NABD-ensemble with inputs truncated by an extra d = 1 and 2 weeks, and report WIS degradation. | E1 | 2026-11-08 | `eval/exploratory.py`: test cells split by phase, defined post hoc from truth vs the last observation (rising >1.25×, flat, falling <0.8×) | In **rising** cells (68% of the FluSight-ensemble's total WIS), NABD-ensemble/FluSight-ensemble = **0.893 (bootstrap 95% CI 0.821–0.984)**. In **flat** cells it is 1.86 (1.55–2.20) and in **falling** cells 1.96 (1.35–2.48). **Reinterpreted after audit R2-M7:** phases are defined from realised truth, so this split favours any model with wider or upper-skewed intervals in rising cells. In rising cells NABD's median log-bias (−0.92) is *worse* than the FluSight-ensemble's (−0.75), so the gain comes from interval width, not from a better trend. It is **not** a finding that NABD 'does well in surges'; it is hypothesis-generating only. EEQ alone would also not have met the primary endpoint (1.198 pooled). | EXPLORATORY; must never be used as a claim. Phases are defined using truth, so this is not usable in real time. It motivates a v2 member aware of turning points, to be pre-registered and tested prospectively (live 2026/27 ledger), not retrofitted to these test seasons. |
